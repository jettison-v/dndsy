10. Decide: change maximum hit points from askdnd (Aid)

Almost everything that changes in play already goes both ways with D&D Beyond. The one realistic gap: maximum hit points going up or down (Aid, a bonus someone sets). askdnd reads it but can't change it, so casting Aid from askdnd doesn't raise anyone's maximum; it's set on D&D Beyond. Adding it means recording the request D&D Beyond's own sheet sends, on a test seat, as was done for preparing spells; then it's small.
