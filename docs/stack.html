Who changes what

Claude works through the command-line tools signed in on this Mac (gh for GitHub, railway for Railway) and the Sentry connection, and has no login to the others, by design.

Claude, from here (you approve each merge)

PieceWhereHow it changes

ChecksGitHub ActionsThe workflow file in the repo. Railway waits for them before deploying.
askdnd-v2's codeRailwayDeploys itself when main changes. Claude follows it with scripts/deploy_check.py and reads its logs.
PostgresRailwayIts shape changes through migrations that ship with the code. Claude can look inside beta (railway ssh), and changes data there only with your OK.
askdnd-backupRailway (cron)Same code as the website; rebuilt when a file it runs changes.

Connections for Claude

A connection (an MCP server) lets Claude use a service directly. Each one is another login to keep safe, so add one only where the command line falls short.

ServiceWhy
SentryConnectedClaude reads each error, its page and line, and marks it resolved, instead of you sending screenshots. Signed in with your Sentry account (organization brett-vw); sees only what Sentry already holds, which is scrubbed.
RailwaySkipThe railway CLI already covers logs, deploys and variables.
GitHubSkipThe gh CLI already covers pull requests, checks and merges.
AWSSkipIt would need a broad key. Key changes are rare, and keeping them in your hands is part of what keeps each key narrow.
CloudflareSkipOne change left (askdnd.ai at launch), and it's a few clicks.
