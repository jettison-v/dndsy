Backstage Mode

One design system, two modes. Table mode is today's, for players and the DM, and doesn't change. Backstage mode is for the people who run askdnd: one plain font, neutral headings, tighter rows, real tables with columns you can sort, the facts in a line at the top, short titles, and the whole window's width (reading text still stops at about 75 characters). Every Backstage page gets it by being built from the design system. Below, the same six pages both ways; switch the page, the mode and the window's width. Rows are clickable.

Why one system, two modesTwo separate systems drift and every piece is built twice. Here the pieces are the same; Backstage mode only changes the values (type, spacing, colour, density) and lays lists out as tables.
What reorganizesEach page opens with its facts in one line, then one table of what it lists (kind, area, state, whose turn, time, as columns), and the selected row's reader to the right, always beside the list.
What staysThe menu bar, the left list, the names, what each page does, who sees it, and every rule (one item opens in a window: The Work Page's pick).
