What's off

  • A line with nothing above it. The list starts with a divider meant to sit under the "add the bridge" steps, which most people never see.
  • The ↗ is a box taller than the words. The rows line up on the words' baseline, so each box hangs below its row, and it's wider than the space set aside for it.
  • Rows change height. "updated 14 hours ago" adds a second line to some rows only, so the gaps between names aren't even.
  • The words sit in a column that changes width. "2 to make by hand" pushes every other word left.

Why this window is harder than the others

The other windows are a stack: a heading, some words, a form, buttons, each full width. This one is a list where every row mixes a name, a status of any length, sometimes a time, and a button, all on one grid. Each new state (the DM Backup adds two) makes the row harder to fit. Any of the three options fixes that by giving every row the same shape.
