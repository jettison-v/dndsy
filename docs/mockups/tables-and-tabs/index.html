Tables and tabs: finished items, search, and Battle's tabs

Two picks from Getting around's batch, the area that keeps every page built from the same pieces. First, finished items and search on every table: Backstage's tables (the Roadmap, Development, Feedback, Documents, History, Usage's calls, Items and the rest) are all built from one piece, so whatever you pick here is built once and every table has it. Second, Battle, Sheet and Plan, the three tabs at the top right of a character's page, which are red while every other "you're here" control in askdnd is blue.

"a filter checkbox to show complete and … a search feature on these tables, we should mock those up" and "You need to mock this up, it is not intuitive" (you, on the Roadmap's item 36)

1 · Finished items and search, on every table

Today some tables show everything, finished and open mixed (Development's Board, Feedback), some hide finished items behind a link at the foot (the Roadmap's History), and Documents has its own three chips. Only History and Documents can be searched. Drawn below on the Roadmap, with made-up items; every table would look the same. A table with nothing that finishes (Usage's calls) gets only the search box.

A · Search and a Show finished box in the table's title row

my pick

Finished items are hidden until you tick Show finished; then they come back at the end, under a Finished label, faded. The search box filters as you type. Both sit at the right of the table's own title, so they belong to that table and nothing else on the page. The tick is remembered on that table.

And the search: does it look in finished items you've hidden?

With A or C, finished items are hidden while you search. Either the search looks only at what's shown, or it finds finished ones too and shows them marked Finished (so a search never misses something because it's done).

2 · Battle, Sheet and Plan

They're filled red when chosen, while the character switch beside the name (Trah · Wolf), Normal form, Table / DM only, Normal / Advantage and every other "this one is chosen" control in askdnd is a blue outline. Red is also askdnd's main action (Roll, Save, Publish), so the chosen tab reads like a button. The outside review (D4) suggested one look for all of them.
