Filters above a list

Every filtered list now shares one filter component. Lists use it two ways: beside the list (the Spell Book, Sheet's lists, Party), where there's room and the list you read is on the right, and above the list, in a narrow column (World, Notes you sent, Battle's See all), where every row the filters take pushes the list down. This draws the second case: the filters fold to one line, "Filters ▸ 2 · Clear", that opens in place. The pieces stay the same: chips, counts, Clear, and each list remembering what's on and whether it's open. The beside-the-list layout doesn't change.
