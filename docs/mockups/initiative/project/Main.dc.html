Your table's way, with askdnd

Brett, Nov 4: keep the anticipation of rolling your own initiative, and let the DM change the order during the fight in case something goes wrong, by dragging it. Where it lives: the Initiative tile on each character's (and creature's) Battle, Table rolls, Party's rows, and D&D Beyond's VTT, where the fight still runs. Once askdnd's own VTT runs, none of the D&D Beyond part is needed.

What stays D&D Beyond's

Adding tokens, Start Combat, Next turn, End Combat, and the DM typing a number in the sidebar: all as now, and askdnd follows them. A roll from the sheet still counts before Start Combat too.

askdnd's rolls reach the VTT the way D&D Beyond's do: through the Game Log, where the DM's open VTT turns an Initiative roll into the number. Marked as askdnd's (board 3).

today's extensionA player's roll for their own character: only how askdnd names the roll changes.

Both need the DM's VTT open, as it always is when a fight runs. Tried on the Mac Mini's test table, Nov 4.

Later: askdnd's own VTT

The same Initiative roll and the same dragging, straight into askdnd's own order. Nothing is sent to D&D Beyond's VTT: no waiting list to hear, no sidebar to fill (Brett: "We do not need to sync combat at all" once it runs).

So everything built here is the part that stays: the roll, Party's rows and the DM's drag. Only the hand-off to D&D Beyond goes.

The rule askdnd keeps, as your table does

Before Start Combat each player sets their own number by rolling (their creatures' too). The DM can roll or type for anyone, as now.

After Start Combat a player's Initiative roll still shows in Table rolls and the Game Log, but doesn't move the order. Only the DM changes it: dragging in askdnd (board 5) or typing in the VTT.
