Each name says what the review looks at. The two on-demand ones are aimed at something when you run them, so they read with it: “Design review: Battle”, “Feature deep-dive: the bridge”. Each has a second name to choose from.

How it starts: askdnd keeps your request and tells Claude's listener, which starts the review in a Claude session on this Mac within about 10 minutes (as the Monday phone sweep starts itself). While it runs, its row says Running; when it's done, Done with what it found.
