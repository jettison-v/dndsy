The reviews we run

Nine kinds of review have shaped askdnd since October: a fresh reviewer reading everything, a day's work checked as one, an area page by page, a feature against the real thing. Each found things the everyday tests can't. Here they are in one place, with what each last changed, so you can choose which run on a schedule, which we call for when needed, and which we retire. The automatic checks (the nightly live test, the phone sweep, backups, Sentry) already have theirs, on Development › Scheduled.

How a scheduled one would run

On its dayA Claude session starts by itself (as the Monday phone sweep does), runs the review with reviewers who didn't build the work, and fixes what's plainly wrong in one pull request.
What reaches youOne page with picks for anything that's your call, in For you, and a line on Development › Scheduled saying it ran and what it found.
On demandYou say “run the outside review” (or press its button on Scheduled, later), and it runs the same way.
RetiredIts page stays in Documents as a record; it isn't run again.
