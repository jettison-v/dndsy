Roll's kinds of roll

Where it lives: the Roll button beside Table rolls' title, on every page at the table. Today it drops a search box with a list under it, and dice for "roll 2d6" sit in a Manual roll fold at the sidebar's bottom. You asked for a window that lays the kinds of roll out instead, with the manual roll inside it. Three ways, drawn at laptop size with Cole's real numbers, plus today's for comparison. Press Roll, then anything in the window; type to narrow it; switch to a phone.

Every way keeps typing: start typing in the window and it narrows, and Enter rolls the first match (lit blue), so ⌘F's Search and today's speed aren't lost. Picking a roll opens the roll window as it does now (Advantage, Guidance, who sees it); the last question asks whether it should.

Today. Roll drops a search box and a list under the button; Manual roll is a fold at the bottom of the sidebar. Fast once you know to type, but nothing is laid out, and the dice are somewhere else.

How they compare

A, by abilityFinds things the way the sheet does: Stealth under Dexterity, beside the Dex save. All 30 rolls and the dice in one look; no tab to guess. The window is big, which suits a laptop; on a phone it's a tall sheet that scrolls.
B, by kindEach tab is short and clear, but you have to know a skill from a check from a save before you find it, which is what players couldn't find in the first place.
C, a list beside the diceThe least to learn, and the dice finally sit beside the rest. Still a list to read down: 30 rows in two columns.
In all threeThe window keeps typing (Enter rolls the first match) and holds the manual roll, so the sidebar's Manual roll fold can go. Proficient rolls carry a dot, and a roll with Advantage says so (Cole's Con save, War Caster).
