A Product Taxonomy: every issue in one Feature, every Feature in one Product Area

You asked for a fixed list to sort requests into, so they group the same way every time and each session starts from the same place. Here it is in two levels, as you suggested: 10 Product Areas, and 62 Features under them, built from docs/MAP.md, the map of every feature I keep.

Where you'll find it

Feedback groups its issues by Product Area, and each issue says its Product Area › Feature at the top. Testing › Where it stands shows which session is working on which Product Area.

Who sorts

Nobody picks a Feature when sending a note. I set it when I sort the note, along with the title. You can change it on the issue with Change…

Where the list lives

The list itself is Manage › askdnd › Product areas. The same list orders docs/MAP.md, so each Feature has the notes on how it works, and a test keeps the two the same.
